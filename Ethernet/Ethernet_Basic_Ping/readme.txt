【 ！】功能简介：
以太网基本功能测试（ping）

【 ！！】注意事项：
需确认开发板上以太网模块与MH芯片连线正常，
需使用RJ45网线连接以太网到电脑，
电脑需要关闭防火墙！
 
【 ！】实验操作：
测试1：默认是静态IP, PING实验
编译下载程序，复位运行，观察串口信息。
电脑windows系统下，win+R，输入cmd，打开命令行窗口，输入ping 192.168.1.102，回车，观察ping的结果。

若无法ping通，可按以下步骤尝试：
电脑连网，确保能上网，然后win+R，输入cmd，打开命令行窗口，输入ping www.baidu.com，回车，观察ping的结果，
确保ping指令没问题。
之后断开电脑除网线外的其它网络（wifi等），再次尝试ping，若仍然无法ping通，请检查以太网模块与MH芯片是否连接正常。

测试2：开启DHCP进行PING实验
  1. 在 lwip_port\lwipopts.h 的文件中 把 #define LWIP_DHCP 0改成#define LWIP_DHCP 1
  2. 把板子连接到与测试同一网关下，编译下载程序，复位运行，观察串口信息，记录DHCP获取的IP地址
  3. 电脑windows系统下，win+R，输入cmd，打开命令行窗口，输入DHCP获取的IP地址，回车，观察ping的结果。

【*】 引脚分配
SWD调试接口：
    SWCLK  (PA13)
    SWDIO  (PA14)
	
串口：
该测试环境默认使用串口1作为printf输出
	USART1  TX  (PA9)
	USART1  RX  (PA10)

ETH:
    管理信号 (MDIO/MDC)
    ETH_MDIO (PA2)
    ETH_MDC (PC1)
    RMII接口信号
    ETH_RMII_REF_CLK (PA1)
    ETH_RMII_CRS_DV (PA7)
    ETH_RMII_RXD0 (PC4)
    ETH_RMII_RXD1 (PC5)
    ETH_RMII_TX_EN (PB11)
    ETH_RMII_TXD0 (PB13)
    ETH_RMII_TXD1 (PB14)
    PHY复位信号
    ETH_PHY_RST (PB10)
