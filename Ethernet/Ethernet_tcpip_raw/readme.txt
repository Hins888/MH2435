【 ！】功能简介：
以太网+LWIP TCP/IP 裸系统测试

【 ！！】注意事项：
需确认开发板上以太网模块与MH芯片连线正常，
需使用RJ45网线连接和电脑同一路由
电脑需要关闭防火墙！
 
【 ！】实验操作：
测试1：默认开启DHCP进行tcpip client实验
1.记下电脑上的IP地址， 在tcp_client.c文件中把服务器地址改成电脑的IP地址，
2. 电脑windows系统下，自己打开对应的测试工具，比如SSCOM32, 设置成TPCServer, 把端口改成 7777 ,开启侦听，
3. 编译程序后并下载到开发板上，复位运行，观察串口信息。
4. 连接成功后，在SSCOM32发送数据给开发板，查看串口是否显示有接收到数据

若无法ping通，可按以下步骤尝试：
电脑连网，确保能上网，然后win+R，输入cmd，打开命令行窗口，输入ping www.baidu.com，回车，观察ping的结果，
确保ping指令没问题。
之后断开电脑除网线外的其它网络（wifi等），再次尝试ping下开发板对应的地址，若仍然无法ping通，请检查以太网模块与MH芯片是否连接正常。

测试2：设置成静态IP进行tcpip client实验
  1. 在 lwip_port\lwipopts.h 的文件中 把 #define LWIP_DHCP 1改成#define LWIP_DHCP 0
  2. 把板子连接到与测试同一网关下，编译下载程序，复位运行，观察串口信息，查看测试程序

【*】 引脚分配
SWD调试接口：
    SWCLK  (PA13)
    SWDIO  (PA14)
	
串口：
该测试环境默认使用串口1作为printf输出
	USART1  TX  (PA9)
	USART1  RX  (PA10)

ETH:
    管理信号 (MDIO/MDC)
    ETH_MDIO (PA2)
    ETH_MDC (PC1)
    RMII接口信号
    ETH_RMII_REF_CLK (PA1)
    ETH_RMII_CRS_DV (PA7)
    ETH_RMII_RXD0 (PC4)
    ETH_RMII_RXD1 (PC5)
    ETH_RMII_TX_EN (PB11)
    ETH_RMII_TXD0 (PB13)
    ETH_RMII_TXD1 (PB14)
    PHY复位信号
    ETH_PHY_RST (PB10)
