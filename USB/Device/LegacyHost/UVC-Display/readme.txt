【 ！】功能简介：
USB UVC摄像头回显到800*480 RGB LCD

【 ！！】注意事项：
1). HOST UVC Lib 支持格式MJPEG显示
2). USE_UVC_MJPEG宏置1，demo选择摄像头MJPEG流，并通过JPEG模块解码为YUYV，再通过DMA2D将YUYV转换为RGB565数据，推送到LTDC模块进行显示输出。
     若配置摄像头为YUY2流模式，需要软件转换为RGB565输出显示。
3). 摄像头参数注意：
    a). 只支持DCT为连续模式的jpeg图，不支持渐进模式
    b). 不支持TIFF交换格式的jpeg图
